图片支持从剪切板粘贴和拖拽文件/图片插入；双击图片会全屏预览。重新打开 `.mbook` 时会恢复图片资源。

## 第一版原型

外观我想要更加接近现实的笔记本或者书籍 双侧都要可写 而不是像市面上大部分的单页编写 有一种摊开了一本书或笔记本在上面书写的感觉
这在很多小说阅读器中有这种外观 并且还有那种翻页的动画效果 尽量参考这种拟物的外观设计
还有最好能有一个目录 每一页的最上方有一行如果输入了内容就作为章节标题 你可以认为我是在搞小说创作
需要可以在当前页插入一张纸或撕掉一张 正文书写区域最好能设计多种风格提供切换 比如横线格像数学本



## 运行原型

需要 Python 3.12 或更新版本。在 Windows 或 Linux 安装依赖后运行：

```text
python -m pip install -r requirements.txt
python main.py
```

这是源码版原型，暂未提供安装包。文档保存为单个 `.mbook` 文件，内部包含 Markdown 页面和图片。新建文档默认打开双页；每页顶部的标题行会进入左侧目录。书页右键菜单可插页、撕页、插图并切换空白、横线、方格纸。

Linux 系统如未提供 `python` 命令，将上述命令中的 `python` 改为 `python3`。

常用快捷键：`Ctrl+N` 新建、`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S` 另存为、`Alt+Left/Right` 翻页、`Ctrl+Shift+O` 显示/隐藏目录、`Ctrl+B/I` 粗体/斜体、`Ctrl+Shift+I` 插图、`F1` 快捷键说明。更多操作可从书页右键菜单进入。

文字颜色：`Alt+0` 默认、`Alt+1` 红、`Alt+2` 橙、`Alt+3` 金、`Alt+4` 绿、`Alt+5` 蓝、`Alt+6` 紫、`Alt+7` 灰。`Esc` 每次关闭一个已激活样式，顺序为颜色、粗体、斜体；未激活的样式会跳过。底部状态栏显示当前样式。

运行不依赖网络。当前版本的富文本编辑使用 Qt 的 Markdown 导入与导出；复杂 GFM 表格及原始 HTML 尚不保证无损保存。
